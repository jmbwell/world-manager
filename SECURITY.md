# Security Policy

## Supported Versions

This project is pre-release. Security fixes are handled on the default branch.

## Reporting a Vulnerability

Please report security issues privately to the project maintainer instead of opening a public issue. Include:

- A description of the issue.
- Steps to reproduce it.
- The affected version or commit.
- Any files or logs needed to understand the problem, with personal data removed.

## Sensitive Data

Do not include personal Minecraft worlds, device identifiers, Apple account data, credentials, private keys, or other secrets in issues, pull requests, logs, screenshots, or test fixtures.
